# Weekly Meter 0.4.0

0.4.0은 위젯 수동 조회를 짧은 foreground service로 분리하고, 내부 여백 조절과 항목별 꾸미기 화면을 추가한 버전입니다. 폰트 경로 수정과 기존 로그인·사용량·꾸미기 설정을 유지합니다.

Galaxy S25 Ultra용 개인용 주간 잔여율 위젯입니다. 실행 중 PC나 외부 중계 서버가 필요하지 않습니다. OpenAI 공식 앱이 아니며 실계정·S25 Ultra 검증은 아직 완료하지 못했습니다.

## 사용하기

1. 앱에서 ChatGPT로 로그인 → 브라우저 열기를 누릅니다. 비밀번호는 폰 브라우저의 공식 OpenAI 화면에서만 입력합니다.
2. 로그인 후 앱으로 돌아옵니다. 최초 연결 때 한 번 사용량을 조회합니다. 공식 화면과 같은 주간 한도를 선택하세요.
3. 위젯 꾸미기에서 설정합니다. 위 미리보기는 고정되고 아래 설정만 스크롤됩니다. 설정은 자동 저장하며 모든 위젯에 공통 적용됩니다.
4. 홈 화면에 위젯을 추가합니다. 기본 1×1, 가로·세로 크기 조절을 지원합니다. 실제 칸 크기·최소 크기 적용은 런처에 따라 다릅니다.

## 위젯 꾸미기

- 퍼센트 / 초기화 시각 / 마지막 성공 조회 시각 / ChatGPT 표시를 각각 켜거나 끕니다.
- 각 행의 글꼴·크기·굵기·색·정렬·세로 위치를 독립적으로 설정하고 행 순서를 바꿉니다.
- 기본 글꼴 외 나눔고딕, 주아, 나눔명조, 나눔고딕코딩을 앱에 포함했습니다. 추가 인터넷이 필요하지 않습니다. 글꼴 크기는 6~96sp, 0.5sp 단위입니다.
- 초기화와 조회 시각은 각각 년·월·일·요일·시·분·초·오전/오후를 켜거나 끌 수 있습니다. 날짜만, 시간만, 모두 숨김이 가능합니다. 12/24시간, 앞자리 0, 날짜 구분자, 한 줄/두 줄, 이름표도 선택합니다.
- 색상은 컬러휠·밝기·HEX·최근 색으로 고릅니다. 배경 투명도·모서리·크기 자동 맞춤도 설정합니다.
- 꾸미기 화면은 고정 미리보기 아래에서 필요한 설정과 요소만 골라 편집합니다. 다른 요소의 긴 설정 목록을 함께 펼치지 않습니다.
- 배치·여백에서 자동 여백을 끄면 좌우·위아래 내부 여백(0~32dp), 줄 사이 간격(0~16dp)을 0.5dp 단위로 조절합니다. 1×1의 내용 영역을 남기도록 과도한 여백은 제한합니다. 런처가 위젯 바깥에 예약한 칸 여백을 제거하는 기능은 아닙니다.
- ChatGPT는 없음 / 문구 / 로고 / 둘 다 중 선택합니다. 로고 크기는 별도 조절합니다. 로고는 OpenAI 원본 형태·여백을 유지하고 검정/흰색으로 표시합니다.
- 1×1 / 2×1 예시 미리보기와 넘침 경고를 제공합니다. 실제 홈 화면 크기·배경·글자 배율은 미리보기와 다를 수 있습니다.

위젯은 평소 선택한 내용만 표시합니다. 정상 사용량이 없거나 캐시가 만료되면 —%입니다. 날짜 원본이 없으면 현재 시각을 만들어 넣지 않고 —로 표시합니다. 날짜 요소를 모두 끄면 해당 행을 그리지 않습니다.

## 조회와 반응 표시

위젯 탭 → 접수 표시 → 실행 중 표시 → 실제 선택 한도의 새 유효 데이터를 저장한 경우에만 성공 체크를 표시합니다. 오류는 느낌표, 대기·연속 요청 제한은 점 표시이며 성공이 아닙니다. 앱에서 오류 설명을 확인합니다.

수동 탭은 Android 작업 대기열에 넣지 않고, 위젯의 명시적 PendingIntent로 짧은 foreground service를 직접 시작합니다. 앱 화면을 열 필요가 없는 경로이며 저장된 연결 정보도 자체 복구합니다. 조회 중 시스템 알림 또는 실행 중 앱 표시가 잠시 나타날 수 있습니다. 자동 주기는 계속 JobScheduler를 사용합니다. 이 변경 경로의 실제 S25 Ultra/One UI 백그라운드 동작은 아직 실기기 미검증입니다.

성공 등 완료 표시 기본 지속시간은 1.0초입니다. 0.1~10.0초를 0.1초 단위 슬라이더·직접 입력으로 설정하거나 반응 표시를 끌 수 있습니다. 조회에는 시간 제한을 두고, 완료 표시를 지운 뒤 짧은 서비스를 종료합니다. Android 프로세스 종료·절전·런처 지연 때문에 정확한 설정 시간에 사라지는 것은 보장하지 않습니다. 다음 렌더 때 만료를 다시 검사합니다.

조회는 위젯 탭, 앱의 지금 새로고침 버튼, 자동 주기, 최초 로그인 완료 때만 요청합니다. 앱 진입·복귀·설정 변경은 네트워크 조회를 시작하지 않습니다. 자동 조회 성공도 사용량과 마지막 성공 조회 시각을 위젯에 반영합니다. 실패나 탭 자체가 마지막 조회 시각을 현재 시각으로 바꾸지 않습니다.

자동 조회는 15/30/60분이며 위젯이 있을 때만 예약합니다. 절전·네트워크·Android 제한으로 지연될 수 있습니다. 연속 탭은 합치고 10초 제한 및 서버 재시도 대기를 존중합니다. 표시값은 마지막 성공한 조회값이지 실시간 보장이 아닙니다.

## 한도와 로그인

Codex 응답의 정확히 7일(604800초 / 10080분) 한도에서 100 - 사용률을 계산합니다. 일반 ChatGPT의 모든 모델 한도를 합친 숫자가 아닙니다. 공식 사용량 화면과 같은 항목을 비교하세요.

앱은 사용량 조회와 인증 교환·갱신만 합니다. 채팅 전송·모델 생성 API·광고·분석 SDK는 없습니다. 실계정에서 한도 전후 비교를 수행한 것은 아닙니다.

외부 브라우저 로그인은 PKCE S256·난수 state를 사용합니다. 로그인 때만 폰 내부 127.0.0.1:1455에서 잠시 응답을 받습니다. PC나 외부 서버가 아닙니다. 비밀번호 UI·WebView·쿠키 추출·토큰 붙여넣기는 없습니다.

토큰은 Android Keystore AES-GCM으로 암호화해 백업 제외 저장소에 보관하고 조회 중 자동 갱신합니다. 영구 로그인을 보장할 수는 없습니다. 서버 만료·권한 철회·앱 데이터 삭제·키 손상·갱신 중 강제 종료에는 재로그인이 필요할 수 있습니다. 로그인 대기 10분은 저장된 세션의 수명이 아닙니다.

공개 Codex 인증 흐름을 참고한 비공식 Android 구현입니다. 토큰은 사용량 읽기 전용으로 제한되지 않습니다. APK 생성·서명 검증을 계정 연결의 안전 보증으로 해석하지 마세요. SECURITY.md에 보안 범위를 정리했습니다.

## 직접 빌드

Windows 검증 환경: JDK 21.0.8, Android platform 36, build-tools 35.0.0, Python 3.

```powershell
.\build-apk.ps1 -Project . -BuildDirectory ..\build-current -SigningDirectory ..\private-signing -Sdk D:\Android\Sdk -Jdk 'C:\Program Files\Android\Android Studio\jbr'
```

매번 새 BuildDirectory를 지정합니다. 결과는 해당 폴더의 dist/WeeklyMeter.apk입니다. 기존 앱에 업데이트하려면 같은 서명 키가 필요합니다. 키·암호·계정정보를 소스나 배포 파일에 넣지 마세요. Linux에서는 ANDROID_HOME을 지정한 뒤 bash build-apk.sh를 실행합니다. Linux 전체 빌드는 별도 미검증입니다.

TEST-RESULTS.txt와 검증 로그는 실제 수행한 검사 범위를 기록합니다. 가짜 서버·저장소·Android 작업 검사와 실제 폰 시험은 다릅니다. 실계정 로그인·Keystore·One UI 홈 화면·재부팅·절전·장시간 동작은 아직 확인해야 합니다.
